# Guias por área

Checklists práticos que consolidam as melhores práticas atuais (Apple HIG, Material 3, WCAG 2.2, WAI-ARIA APG, NN/g, Baymard, GOV.UK, Refactoring UI, Emil Kowalski, Rauno Freiberg). Texto original WebCode; as fontes ficam no fim de cada guia.

Leia só o guia da área em que está trabalhando. Cada item é verificável: se não dá para dizer "sim" ou "não", o item está mal escrito e deve ser corrigido aqui.

| Guia | Quando ler |
| --- | --- |
| [ui.md](ui.md) | Hierarquia, espaço, tipografia, cor, ícones, profundidade |
| [ux.md](ux.md) | Fluxos, estados, copy, erros, performance percebida, onboarding |
| [a11y.md](a11y.md) | WCAG 2.2 AA aplicado, teclado, leitores de tela, critérios novos do 2.2 |
| [forms.md](forms.md) | Campos, validação, máscaras BR, checkout, autenticação |
| [tables.md](tables.md) | Tabelas de dados, listas densas, filtros, ações em lote |
| [navigation.md](navigation.md) | Sidebar, tabs, breadcrumbs, tab bar, busca, deep links |
| [overlays.md](overlays.md) | Dialog, alert dialog, sheet, drawer, popover, tooltip, toast |
| [data-viz.md](data-viz.md) | Dashboards, KPIs, gráficos, tempo real |
| [ai-interfaces.md](ai-interfaces.md) | Chat, streaming, ações de agente, confiança e controle |
| [mobile.md](mobile.md) | App mobile e PWA: safe areas, toque, gestos, transições, teclado, offline, equivalências Expo |
| [../motion.md](../motion.md) | Durações, curvas, springs (tokens) |

Regra de ouro: quando um guia conflitar com `principles.md`, o princípio ganha. Quando conflitar com o Design Freeze/`DESIGN.md` do projeto, o projeto ganha.
